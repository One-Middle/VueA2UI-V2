# 模块目标设计

`20-design/modules/` 保存模块目标设计，回答每个模块理想上应该负责什么、对外暴露什么、未来如何演进。

当前源码真实实现以 `../../40-implementation/modules/` 为准。本目录可以描述未实现目标，但必须标注状态。

## 推荐模块

- `agent.md`
- `backend.md`
- `frontend.md`
- `renderer.md`
- `shared.md`
- `integration.md`

## 模板

```md
# <Module> 目标设计

> 文档角色：设计
> 是否真相源：是，目标设计真相源
> 更新触发：模块长期职责、目标能力、对外接口或演进方向变化

## 1. 模块定位
## 2. 目标能力
## 3. 不负责的事情
## 4. 对外接口
## 5. 内部结构设计
## 6. 核心流程
## 7. 数据与状态模型
## 8. 与其他模块的关系
## 9. 当前状态
## 10. 演进计划
```
