# 07 — Workflow Failure And Retry Inline

**What to build:** Workflow failures and retry actions are presented inside the AI Workflow Message where the failed execution is already visible.

**Blocked by:** 06 — Artifact Summaries In Workflow Message.

**Status:** ready-for-agent

- [ ] Failed Workflow state appears inside the AI Workflow Message.
- [ ] Failure reason or validation summary is visible without opening the old Workflow panel.
- [ ] Retry action appears inside the AI Workflow Message when retry is available.
- [ ] Retry uses the existing WorkflowAction API.
- [ ] Retrying updates the same Workflow Message instead of creating a separate Workflow panel experience.
