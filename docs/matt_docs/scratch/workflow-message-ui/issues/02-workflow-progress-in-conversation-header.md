# 02 — Workflow Progress In Conversation Header

**What to build:** The conversation area shows the current Workflow progress at the top, so the creator can see whether the Agent is planning, generating, validating, previewing, or committing.

**Blocked by:** 01 — Workspace Two-Column Shell.

**Status:** ready-for-agent

- [ ] The conversation header renders the fixed Workflow Step sequence: Plan, Generate, Validate, Preview, Commit.
- [ ] Completed or confirmed steps appear done.
- [ ] Running steps appear active.
- [ ] Awaiting-confirmation steps appear waiting.
- [ ] Failed steps appear error.
- [ ] Pending and skipped steps have distinct non-active states.
- [ ] The header handles sessions with no active Workflow without visual breakage.
