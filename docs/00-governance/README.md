## 项目级 Skills

`skills/` 保存用于维护本项目文档系统的 Skill 源文件：

- `skills/docs-system-init/`：初始化或迁移项目文档系统。
- `skills/docs-change-maintenance/`：功能新增、修改、重构或修复时同步维护文档。

这些 Skill 当前作为项目规范随仓库维护；如需在 Codex 中全局触发，可复制或安装到用户级 Codex Skills 目录。
