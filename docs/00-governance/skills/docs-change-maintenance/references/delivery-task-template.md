# Delivery Task Template

Create a directory:

```text
50-delivery/planning/YYYY-MM-short-topic/
  context.md
  plan.md
  checklist.md
  progress.md
  decisions.md
  result.md
```

## context.md

- Background
- Problem
- Goal
- Non-goals
- Affected modules
- Relevant truth sources

## plan.md

- Approach
- Phases
- Files likely to change
- Contract impact
- Validation plan

## checklist.md

Use task checkboxes. Keep each item executable.

## progress.md

Record meaningful work updates and discoveries.

## decisions.md

Record local decisions that are too small for ADR but important for the task.

## result.md

- Summary
- Changed code
- Changed docs
- Verification
- Backfilled truth sources
- Remaining risks
