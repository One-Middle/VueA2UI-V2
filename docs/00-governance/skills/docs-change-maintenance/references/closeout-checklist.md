# Closeout Checklist

Before finishing a code or docs-maintenance task:

1. Run relevant tests or explain why not run.
2. Check `git status --short`.
3. Confirm cross-module changes are reflected in `30-contracts/`.
4. Confirm real implementation changes are reflected in `40-implementation/`.
5. Confirm product/design changes are reflected in `10-product/` or `20-design/`.
6. Confirm delivery task result is updated if a task directory exists.
7. Search for stale old paths or contradicted facts.
8. Mention intentionally untouched user changes.
9. Summarize changed docs and verification.
